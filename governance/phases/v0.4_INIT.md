# HDS JSON-safe Output v0.4 — META-ONLY EXTENSION — INIT

STATUS: INIT
SCOPE: Additive extension limited strictly to `meta` section

## Baseline
- Base contract: HDS JSON-safe Output v0.3 (LOCKED)
- Adapter: HOI → HDS v0.3A (LOCKED)
- Audit Snapshot: v0.3A (LOCKED)

## Objective
Extend the HDS JSON output with additional metadata fields that:
- improve traceability
- improve audit correlation
- improve execution context visibility

WITHOUT altering decision semantics or option structure.

## Allowed Changes (ONLY)
Additive fields under `meta`, such as:
- meta.timestamp (ISO 8601)
- meta.trace_id (opaque string)
- meta.correlation_id (opaque string)
- meta.source (e.g. "cli", "api")
- meta.execution_context (string / object, non-semantic)
- meta.audit_hint (string, non-interpreted)

## Explicitly Forbidden
- Any modification to `options[]`
- Any modification to existing meta fields from v0.3
- Ranking, scoring, prioritization
- Interpretation of HOI input
- Memory, learning, adaptation
- Signal detection
- Any implicit or explicit authority shift

## Invariants (Reaffirmed)
- HOI retains absolute legitimacy
- HDS never decides
- LLM is a subordinate language executor
- Audit remains passive (stdout capture)

## Compatibility
- Must remain backward-compatible with v0.3 consumers
- v0.3 snapshot remains valid reference
- v0.4 snapshot will be additive only

## Deliverables (v0.4)
- Updated JSON schema (meta-only)
- New audit snapshot
- INIT / LOCK / COMPLETE documents
