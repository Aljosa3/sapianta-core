## 1. NAMEN FAZE v0.5

Faza v0.5 je namenjena **izključno zasnovi runtime arhitekture**.

V tej fazi:
- se runtime NE implementira
- se moduli NE izvajajo
- se ne testira execution poti
- se ne povezuje modulov

Cilj faze je:
> **zasnovati, razumeti in normativno omejiti runtime, preden obstaja.**

---

## 2. IZHODIŠČE FAZE

Faza v0.5 izhaja iz zaključenega stanja v0.4:

- Execution Boundary je definirana (SCF-04)
- Guard Lifecycle ima izključno odločitveno avtoriteto
- Runtime admission preconditions so zaklenjeni (SCF-05)
- Sinergija modulov je normativno omejena (SCF-03)

Ta faza NE reinterpretira nobenega od zgornjih dokumentov.

---

## 3. DOVOLJEN OBSEG DELA (DESIGN-ONLY)

V fazi v0.5 je dovoljeno:

- konceptualna zasnova runtime sloja
- definiranje runtime komponent (poimenovanje, odgovornosti)
- zasnova interakcijskega registra (conceptual)
- zasnova Guard → Runtime vmesnika
- definiranje stanj in prehodov (brez kode)

Vse zgoraj je **opisno, ne izvedbeno**.

---

## 4. IZRECNE PREPOVEDI

V fazi v0.5 INIT je izrecno prepovedano:

- pisati runtime kodo
- dodajati `runtime/*` v Git
- izvajati ali simulirati module
- implementirati Guard mehanizme
- testirati execution

Vsaka kršitev pomeni:
> **prezgoden prehod iz designa v implementacijo.**
