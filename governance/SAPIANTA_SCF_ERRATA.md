## 3. POJASNJENE REFERENČNE NESKLADNOSTI

### 3.1 Sklic na obseg System Protocols

V dokumentu:
- governance/SAPIANTA_SYSTEM_FRAMEWORK.md

je navedeno:
> »SCF vključuje vse System Protocols (SP-0 … SP-9)«

Dejansko stanje repozitorija na dan LOCK-a:
- samostojni System Protocol dokumenti obstajajo za:
  - SP-9, SP-9A, SP-10, SP-11, SP-12, SP-13, SP-14, SP-15, SP-16
- samostojni System Protocol dokumenti za SP-0 … SP-8 **ne obstajajo**

Pojasnilo:
- navedba »SP-0 … SP-9« se razume kot **zgodovinska ali generična referenca**
- veljavni in normativni System Protocols so tisti,
  ki so **dejansko prisotni in označeni v repozitoriju**
