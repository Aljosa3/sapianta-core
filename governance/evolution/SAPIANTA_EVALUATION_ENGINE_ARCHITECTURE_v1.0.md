# SAPIANTA_EVALUATION_ENGINE_ARCHITECTURE_v1.0

Status: ARCHITECTURAL SPECIFICATION
Layer: L3 Governance
Scope: Evaluation Engine
Version: 1.0


------------------------------------------------------------
1. PURPOSE
------------------------------------------------------------

This document defines the architecture of the
SAPIANTA Evaluation Engine.

The Evaluation Engine analyzes experiment results
and determines the performance of generated strategies.

Its role is to transform raw experiment outputs
into structured performance evaluations that guide
strategy evolution and promotion.


------------------------------------------------------------
2. SYSTEM POSITION
------------------------------------------------------------

The Evaluation Engine operates after experiment execution.

Architecture position:

Experiment Engine
↓
Artifact Registry
↓
Evaluation Engine
↓
Strategy Evolution Engine
↓
Promotion System
↓
Domain Modules


------------------------------------------------------------
3. CORE RESPONSIBILITIES
------------------------------------------------------------

The Evaluation Engine performs the following tasks:

• analyze experiment results
• compute evaluation metrics
• rank strategies
• identify evolution candidates
• identify promotion candidates


------------------------------------------------------------
4. EVALUATION INPUTS
------------------------------------------------------------

Evaluation uses artifacts generated by experiments.

Input artifacts include:

• experiment artifacts
• strategy artifacts
• dataset artifacts
• execution metadata


------------------------------------------------------------
5. EVALUATION METRICS
------------------------------------------------------------

Evaluation metrics depend on the domain.

Typical metrics include:

• profitability
• drawdown
• stability
• robustness
• volatility
• execution efficiency

Metrics must be deterministic.


------------------------------------------------------------
6. STRATEGY RANKING
------------------------------------------------------------

Strategies are ranked based on evaluation metrics.

Ranking methods may include:

• weighted score
• Pareto efficiency
• robustness scoring
• regime-specific evaluation


------------------------------------------------------------
7. EVOLUTION CANDIDATES
------------------------------------------------------------

The Evaluation Engine identifies strategies that
should be used for further evolution.

Criteria include:

• strong performance
• stability across regimes
• promising parameter configurations


------------------------------------------------------------
8. PROMOTION CANDIDATES
------------------------------------------------------------

Strategies that satisfy promotion thresholds
may be flagged as promotion candidates.

Promotion criteria include:

• reproducible experiment results
• superior evaluation metrics
• governance compliance


------------------------------------------------------------
9. EVALUATION ARTIFACT
------------------------------------------------------------

Evaluation results must be stored as artifacts.

Evaluation Artifact fields include:

• evaluation_id
• strategy_reference
• evaluation_timestamp
• metric_results
• ranking_score
• candidate_status


------------------------------------------------------------
10. GOVERNANCE REQUIREMENTS
------------------------------------------------------------

The Evaluation Engine must comply with
SAPIANTA governance.

Requirements include:

• deterministic metric computation
• artifact registration
• traceable lineage
• reproducible evaluation


------------------------------------------------------------
11. SYSTEM ROLE
------------------------------------------------------------

The Evaluation Engine transforms experiment results
into structured decision signals.

It enables SAPIANTA to determine which strategies
should evolve and which strategies should advance
toward operational use.
