------------------------------------------------------------
1. PURPOSE
------------------------------------------------------------

This document defines the AGI trajectory model for SAPIANTA.

The trajectory describes the evolution path from a rule-based
system to a fully autonomous research system.

The purpose of the trajectory model is to:

• define system development phases
• identify critical capabilities
• guide long-term architecture decisions
• ensure governance-safe system evolution


------------------------------------------------------------
2. AGI TRAJECTORY MODEL
------------------------------------------------------------

SAPIANTA evolves through multiple architectural phases.


------------------------------------------------------------
PHASE 0 — STATIC SYSTEM
------------------------------------------------------------

Architecture:

human design
↓
rule-based execution

Characteristics:

• no autonomous learning
• no experimentation
• deterministic rule execution

Example systems:

traditional trading bots
rule-based expert systems


------------------------------------------------------------
PHASE 1 — EXPERIMENT SYSTEM
------------------------------------------------------------

Architecture:

human defines experiment
↓
system executes experiment
↓
human evaluates results

Characteristics:

• experiments exist
• research still human-driven
• limited automation

Example systems:

ML research pipelines


------------------------------------------------------------
PHASE 2 — AUTONOMOUS RESEARCH SYSTEM
------------------------------------------------------------

Architecture:

information space
↓
idea discovery engine
↓
idea artifacts
↓
AI Software Factory (ASF)
↓
experiment pipeline
↓
artifact registry
↓
knowledge engine
↓
strategy evolution
↓
domain integration
↓
decision spine
↓
execution
↓
world state

Characteristics:

• automated idea discovery
• automated experiment generation
• automated strategy evolution
• knowledge extraction from experiments


------------------------------------------------------------
PHASE 3 — SELF-IMPROVING RESEARCH SYSTEM
------------------------------------------------------------

The system begins improving its own research infrastructure.

Architecture:

research pipeline
↓
meta-experiments
↓
improved discovery engines
↓
improved ranking algorithms
↓
improved experiment design

Capabilities:

• research optimization
• experiment design evolution
• improvement of discovery engines
• improvement of mutation engines


------------------------------------------------------------
PHASE 4 — AUTONOMOUS DOMAIN CREATION
------------------------------------------------------------

The system gains the ability to create new operational domains.

Architecture:

idea
↓
domain specification
↓
domain module
↓
integration
↓
research loop

Examples of new domains:

energy optimization
robotics control
biomedical discovery
logistics optimization


------------------------------------------------------------
3. CRITICAL AGI COMPONENTS
------------------------------------------------------------

The following components are required for the transition
toward AGI-class research capability.

Global Knowledge Graph

Provides structured representation of system knowledge.

Long-Horizon Research Planner

Enables planning of multi-step research programs.

Autonomous Domain Builder

Allows the system to create new domains.

Recursive Self-Improvement Engine

Allows improvement of research infrastructure.


------------------------------------------------------------
4. GOVERNANCE CONSTRAINTS
------------------------------------------------------------

All system evolution must comply with the
Governed Autonomous Development (GAD) model.

Development cycle:

idea
↓
research
↓
artifact
↓
governance validation
↓
promotion
↓
deployment

Autonomous components may not modify the system without
governance approval.


------------------------------------------------------------
5. SAFETY ARCHITECTURE
------------------------------------------------------------

The system must respect the four-layer authority structure.

Human Authority
↓
Governance Layer
↓
Autonomous Research Layer
↓
Execution Layer
↓
Real World

This structure forms the Capability Firewall of the system.


------------------------------------------------------------
6. LONG TERM VISION
------------------------------------------------------------

The final system represents a governed autonomous research
organization.

Capabilities:

continuous discovery
cross-domain knowledge synthesis
self-improving research infrastructure
safe real-world deployment


------------------------------------------------------------
7. SYSTEM POSITION TODAY
------------------------------------------------------------

The current architecture places SAPIANTA between
Phase 2 and Phase 3 of the trajectory.

The system already includes:

idea discovery concepts
AI Software Factory
experiment pipeline
artifact registry
strategy evolution engine
decision spine
governance validation

The next architectural milestone is the introduction of:

Global Knowledge Graph
Long-Horizon Research Planner
