# Knowledge Anchor Referencing Protocol

## Status
- Phase: FAZA 23A
- Type: Design-only
- Execution: Forbidden
- Protocol state: Authoritative

---

## 1. Purpose

This document defines the **mandatory protocol** by which the SAPIANTA
system references Knowledge Anchors during reasoning, planning, and
response generation.

Its purpose is to:
- eliminate implicit authority
- prevent inferred or assumed rules
- make all normative claims traceable
- enforce explicit grounding of decisions

---

## 2. When Referencing Is Required

A Knowledge Anchor **MUST** be explicitly referenced when:

- a rule is stated as binding
- a restriction or prohibition is asserted
- a capability is denied or allowed
- a phase lock is enforced
- execution is permitted or refused
- a design decision is justified normatively

If no anchor applies, this must be stated explicitly.
