# ADR-0005: Swagger Enterprise Exposure

## Status

Accepted for product demo direction.

## Context

Enterprise technical audiences need evidence that the demo has inspectable API surfaces, not only a visual presentation.

## Decision

Include Swagger/API exposure as part of the enterprise demo flow where implemented endpoints are available.

## Product Rationale

Swagger exposure supports technical credibility and helps bridge UI storytelling with inspectable implementation surfaces.

## Boundaries

Swagger/API exposure must only show or claim implemented behavior. It does not imply full enterprise readiness, runtime governance activation, policy engine activation, or governed enforcement.

## Consequences

Future API demo work should keep endpoint descriptions deterministic, accurate, and limited to verified implementation.
