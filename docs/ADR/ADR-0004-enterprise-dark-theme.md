# ADR-0004: Enterprise Dark Theme

## Status

Accepted for product UI direction.

## Context

The demo should feel like an enterprise decision inspection surface rather than a consumer app or marketing landing page.

## Decision

Use a dark enterprise theme for the server/demo UI direction.

## Product Rationale

A restrained dark theme supports presentation environments, validation status contrast, audit viewer focus, and technical credibility.

## Boundaries

The visual theme is product presentation only. It does not imply runtime maturity, compliance certification, or active enforcement.

## Consequences

UI work should remain readable, restrained, and operational. Decorative choices should not reduce audit or explanation clarity.
