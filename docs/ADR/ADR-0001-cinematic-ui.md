# ADR-0001: Cinematic UI

## Status

Accepted for product demo direction.

## Context

The server/demo branch needs a strong first impression for enterprise presentations. Viewers should understand quickly that SAPIANTA is serious, inspectable, and focused on AI-assisted decision validation.

## Decision

Use a cinematic UI direction for the demo entry experience, while keeping audit, validation, explanation, and limitation surfaces visible.

## Product Rationale

Cinematic presentation helps establish product identity before the walkthrough moves into audit and API details. It supports demo clarity without changing runtime architecture.

## Boundaries

This ADR does not activate runtime governance, enforcement, policy logic, or Decision Spine behavior.

The cinematic layer must not imply hidden autonomous control or certified compliance.

## Consequences

The UI should balance polish with credibility. Visual design should improve comprehension, not obscure limitations.
