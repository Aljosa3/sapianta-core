# 4. SELF-HEALING SYSTEM

## 4.1 Error Classes Supported

### SyntaxError (TARGETED REPAIR)

- function-level repair
- uses SyntaxError.lineno
- preserves other functions
- avoids full file rewrite

→ Transition: bulk repair → surgical repair

---

### NameError / ImportError

- variable stubs (x = 0)
- module stubs (module = None)

→ deterministic runtime repair

---

### TypeError

Supports:

- missing positional args
- unexpected keyword args
- multiple values for argument

→ includes call-site + function fixes

---

## 4.2 Function Targeting Layer (FTL v2)

- extracts failing function from pytest output
- resolves correct file
- avoids mis-targeting (fallback.py issue resolved)

→ enables semantic repair

---

## 4.3 Repair Loop

- iterative (multi-attempt)
- stagnation detection
- strategy deduplication
- module cache reset between runs

---
