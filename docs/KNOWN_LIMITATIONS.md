# Known Product Limitations

## Purpose

This document prevents accidental overclaiming during demos, enterprise presentations, and AI-assisted development sessions.

It is documentation-only and does not change runtime behavior.

## Dormant Governance

Governance remains dormant in the server/demo branch.

The demo may present governance concepts or future direction, but it does not activate runtime governance behavior.

## No Runtime Governance Activation

Runtime governance activation is not active.

No document in this product memory layer should be interpreted as an activation instruction, runtime contract, enforcement trigger, or policy engine change.

## No Autonomous Governance Execution

The server/demo branch does not perform autonomous governance execution.

SAPIANTA should not be presented as an autonomous agent, autonomous regulator, or self-governing system.

## No Governed Enforcement

Governed enforcement is not active in this demo branch.

The demo should not claim that decisions are enforced, blocked, approved, or governed by active runtime policy unless that capability is separately implemented and verified.

## Demo Limitations

Current demo limitations:

- presentation-oriented branch
- product story may be ahead of complete implementation
- audit views are demo surfaces unless separately verified as production-ready
- EU AI Act narrative is explanatory, not a compliance claim
- Swagger/API exposure supports technical inspection but does not imply full enterprise readiness
- deterministic validation should only be claimed for implemented flows

## Current Non-Goals

Current non-goals:

- governance evolution memory
- runtime governance activation
- enforcement activation
- Decision Spine changes
- policy engine changes
- autonomous AGI framing
- legal compliance certification
- replacement of human review
- hidden activation semantics

## Safe Demo Reminder

The safest product message is:

"SAPIANTA is a product demo for inspecting AI-assisted decisions through deterministic validation, visible explanations, and audit-oriented presentation. Governance remains dormant, and the demo does not claim legal compliance or active enforcement."
