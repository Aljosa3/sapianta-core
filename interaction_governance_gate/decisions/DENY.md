## GOVERNANCE DECISION: DENY

### Definition
DENY is a declarative outcome indicating that the input message
violates one or more admissibility requirements.

### Effect
- The message MUST NOT proceed beyond the Governance Gate.

### Guarantees
- Deterministic rejection
- No side effects

### Forbidden Implications
- No error explanation
- No remediation guidance
- No retry semantics
- No escalation semantics
