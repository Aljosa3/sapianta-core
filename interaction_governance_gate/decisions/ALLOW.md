## GOVERNANCE DECISION: ALLOW

### Definition
ALLOW is a declarative outcome indicating that the input message
meets all admissibility requirements of the Governance Gate.

### Effect
- The message MAY proceed to the next boundary (Boundary Adapter).
- No execution is implied.

### Guarantees
- No mutation of the message
- No enrichment
- No interpretation
