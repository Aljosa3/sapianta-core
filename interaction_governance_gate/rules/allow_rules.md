## ADMISSIBILITY RULES — ALLOW

### Rule A-1
The input MUST originate from the Interaction layer.

### Rule A-2
All required fields MUST be present and structurally valid.

### Rule A-3
The input MUST NOT contain any forbidden fields or references.

### Outcome
If all ALLOW rules are satisfied, the gate MAY emit decision ALLOW.
