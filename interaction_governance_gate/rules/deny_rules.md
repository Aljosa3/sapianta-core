## ADMISSIBILITY RULES — DENY

### Rule D-1
The input is missing one or more required fields.

### Rule D-2
The input contains forbidden references or flags.

### Rule D-3
The input violates structural constraints of the input contract.

### Outcome
If any DENY rule is satisfied, the gate MUST emit decision DENY.
