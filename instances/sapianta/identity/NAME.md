This document declares the official name of the Sapianta instance.
It does not assign capability.
It establishes identity.

---

## 0. Purpose of This Document

This document exists to:

- formally declare the name of this Sapianta instance,
- anchor identity across documentation, governance, and implementation,
- prevent ambiguity between multiple instances,
- provide a stable reference for audit and control.

A name is an identity boundary.

---

## 1. Declared Instance Name

The official name of this instance is:

**Sapianta**

This name refers to:

- the complete instance as defined under `instances/sapianta/`,
- all behaviors, documents, and capabilities scoped to this instance,
- the advisory system operating under the declared purpose.

No other system may claim this identity without explicit governance approval.

---

## 2. Name Scope and Usage

The name **Sapianta**:

- identifies this specific instance,
- does not identify the Core itself,
- does not imply authority beyond this instance,
- does not grant execution or decision rights.

The Core remains anonymous and universal.
The name applies only to the instance.

---

## 3. Prohibition of Name Overloading

The instance name MUST NOT be used to:

- imply autonomous agency,
- suggest execution authority,
- mask human responsibility,
- represent outcomes as originating from the system itself.

Statements such as “Sapianta decided” are invalid.

Correct phrasing attributes decisions to the Core
and responsibility to humans.

---

## 4. Relationship to Other Instances

Other Sapianta-based instances:

- MUST use distinct instance names,
- MUST declare their own identity documents,
- MUST NOT share this name implicitly.

This name is not a template.
It is an assignment.

---

## 5. Name Invariance

The declared name:

- remains stable across versions,
- does not change with implementation details,
- is not altered by configuration or deployment.

Changing the instance name requires:

- a new version of this document,
- explicit governance approval,
- consistency review across all references.

---

## 6. Minimal Conclusion

This instance is named **Sapianta**.

The name defines identity,
not authority.
