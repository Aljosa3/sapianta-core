## FORBIDDEN COMMUNICATION DIRECTIONS AND ACTIONS

### Rule FD-1
Interaction MUST NOT invoke Core logic.

### Rule FD-2
Interaction MUST NOT assume Core state, intent, or reasoning.

### Rule FD-3
Interaction MUST NOT interpret Handshake Response semantics.

### Rule FD-4
Interaction MUST NOT transform, enrich, or decompose responses.

### Rule FD-5
Interaction MUST NOT condition behavior based on Core responses.

### Rule FD-6
Interaction MUST NOT reference Canon content in any message.

### Rule FD-7
Interaction MUST NOT persist, replay, or cache handshake data.

### Rule FD-8
No execution signals, flags, or triggers are permitted.
